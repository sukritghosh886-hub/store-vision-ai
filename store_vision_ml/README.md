# Store Vision AI — Machine Learning Pipeline

This directory contains the machine-learning layer for the
Store Vision AI project.

## Current ML Component

The first ML component is a Random Forest classifier designed
to estimate theft-risk behavior from structured store-event
features.

### Current input features

- dwell_time
- item_interactions
- items_picked
- items_returned
- movement_speed
- shelf_visits
- exit_without_billing
- billing_mismatch

### Current output

The model returns:

- prediction
- risk level
- risk probability

## Pipeline

Computer Vision
       ↓
Tracking / Store Events
       ↓
Feature Extraction
       ↓
Random Forest
       ↓
Theft-Risk Prediction
       ↓
Store Vision AI Alert

## Current Training Data

The initial training dataset is synthetic.

Therefore, this version is a machine-learning prototype and
must not be represented as a validated real-world theft
detection system.

## Training

Install dependencies:

    pip install -r requirements.txt

Generate the synthetic dataset:

    python generate_dataset.py

Train the model:

    python train_model.py

Run a test prediction:

    python predict.py

## Future Development
